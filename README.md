# Entrenamiento de Velocista

Script legítimo de Roblox para un sistema de entrenamiento de velocidad.

## ¿Qué hace?

Cuando un jugador se coloca encima del Part llamado **TrainingPad**, su velocidad (`WalkSpeed`) aumenta poco a poco de forma realista.

- No salta tiempos
- No es un cheat
- El jugador tiene que permanecer encima del pad para seguir entrenando

## Cómo usarlo

1. Crea un **Part** en el Workspace (puedes llamarlo `TrainingPad`).
2. Inserta un **Script** dentro de ese Part.
3. Pega el código del archivo `TrainingPad.lua`.
4. Ajusta estos valores si quieres:
   - `SPEED_GAIN` → cuánta velocidad gana por segundo
   - `MAX_SPEED` → velocidad máxima
   - `TRAINING_COOLDOWN` → tiempo entre cada aumento

## Notas

Este script es completamente legítimo y está pensado para juegos de entrenamiento o roleplay.
